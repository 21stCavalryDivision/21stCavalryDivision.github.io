21ST CAVALRY DIVISION WEBSITE
=============================

This is a static GitHub Pages website.

LIVE SITE REPOSITORY NAME
Use: 21stCavalryDivision.github.io

FILES
- index.html        Home page
- recruitment.html Recruitment application
- training.html     Training pipeline
- orbat.html        ORBAT / leadership roster
- resources.html    SOP library
- server.html       Server and mod information
- media.html        Screenshot gallery
- styles.css        Site styling
- script.js         Navigation, animation, application copy button
- assets/           Images and graphics

DISCORD
The site is already configured for:
https://discord.gg/PCxE5jTYZ

WHAT YOU SHOULD CUSTOMIZE NEXT
1. ORBAT names and ranks in orbat.html.
2. Server IP/hostname and port in server.html.
3. Current mod list or Workshop collection in server.html.
4. Upload your actual logo and operation screenshots to assets/.
5. Replace gallery placeholders in media.html with <img> tags.
6. Replace assets/hero-placeholder.svg with your preferred background image and update the CSS hero background path if necessary.

GITHUB UPDATE METHOD
Upload/replace the files in the root of the 21stCavalryDivision.github.io repository and commit the changes. GitHub Pages will redeploy automatically.
